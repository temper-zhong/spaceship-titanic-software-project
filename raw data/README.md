# Data directory

Download the following files from the Kaggle [Spaceship Titanic data page](https://www.kaggle.com/competitions/spaceship-titanic/data) and place them in this directory:

- `train.csv`
- `test.csv`
- `sample_submission.csv`

The competition data is intentionally excluded from GitHub. Do not rename the files because the training script and tests use these exact names.
